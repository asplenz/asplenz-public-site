# Compliance Decision Platform<br/>for Regulated Industries

Every compliance decision can be executed, explained and replayed years later.

## The three pillars

### Compliance operating model

Policies, Rules, Targets, Approvals, Overrides, Governance. The objects a compliance department actually manipulates, native in the runtime.

### Deterministic execution

Same inputs. Same decision. Every time. AI is kept strictly out of the decision path : it only explains, never decides.

### Replayable governance

Every decision can be reconstructed years later, together with the rule versions, approvals and governance decisions that produced it.

## Built for the shape of regulated work

- **Multi-audience attribution** : the same rule applies differently to a Singapore desk, a Hong Kong desk, and a compliance oversight seat. One row in the registry, three audiences, zero duplication.
- **First-class overrides** : exceptions are objects with a scope, a duration, a justification and a decider. Not a boolean flag hidden in your codebase.
- **Multi-channel** : REST API for OMS integrations, MCP for AI agents, Slack and email for the human loop. The compliance conversation reaches its participants where they already are.

# Compliance Decision Platform<br/>pour les Secteurs Régulés

Chaque décision compliance peut être exécutée, expliquée et rejouée des années plus tard.

## Les trois piliers

### Modèle opérationnel compliance

Policies, Rules, Targets, Approvals, Overrides, Governance. Les objets qu'un département compliance manipule réellement, natifs dans le runtime.

### Exécution déterministe

Mêmes entrées. Même décision. À chaque fois. L'IA reste strictement hors du chemin de décision : elle explique, elle ne décide jamais.

### Gouvernance rejouable

Chaque décision peut être reconstituée des années plus tard, avec les versions de règles, les approbations et les décisions de gouvernance qui l'ont produite.

## Conçu pour la forme réelle du travail régulé

- **Attribution multi-audience** : la même règle s'applique différemment à un desk Singapour, un desk Hong Kong, un poste d'oversight compliance. Une ligne dans le registre, trois audiences, zéro duplication.
- **Overrides de première classe** : les exceptions sont des objets avec un scope, une durée, une justification et un décideur. Pas un booléen caché dans votre code.
- **Multi-canal** : API REST pour l'OMS, MCP pour les agents IA, Slack et email pour la boucle humaine. La conversation compliance atteint ses participants là où ils travaillent déjà.
